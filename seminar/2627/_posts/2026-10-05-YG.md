title : "Streamification - Migrating Imperative Loops to Declarative Streams in Java"

The release of Java 8 in March 2014, marked a paradigm shift in the Java ecosystem, introducing lambda expressions and the Stream API. This transition encouraged a shift from imperative ("how") to declarative ("what") programming, offering benefits such as reduced boilerplate and simpler, more efficient parallelisation. However, to reap the benefits of the Stream API requires developers to manually rewrite their loops using the Stream API, which is error-prone and time-consuming. Only one approach, Kayak, has been proposed to support developers. Unfortunately, it only applies to loops operating on collections of integers, and it is incomplete (not applicable to real code). Therefore, we propose a (semi-)automated approach that identifies and converts Java loops into equivalent Java Stream API structures. We improve on Kayak by proposing an end-to-end approach and its implementation that identifies migration opportunities and generates sound code using the Stream API, guaranteed to be equivalent through static analyses and automated proofs. We are currently working on a proof-of-concept that implements the complete approach. Ultimately, this (semi-)automated tool gives developers a practical, scalable way to safely modernise legacy codebases, improving readability and unlocking concurrency potential.
